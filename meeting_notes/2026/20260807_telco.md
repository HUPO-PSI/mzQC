## Mass Spectrometry Imaging

* Patrick presented an imaging mzQC use case based on the matrix data type.
* Spatial metrics such as per-pixel TIC and reference mass error can reveal local contamination and tissue-related effects that would be lost in single-value summaries.
* Matrix-based mzQC files can become large, although compression should reduce file size.
* Several new CV terms are required, and an existing PSI-MS search-width term also needs correction.
* The group supported including imaging in the manuscript, while avoiding excessive overlap with Patrick’s future MSI publication.
* **Action – Patrick Boschmann:** Prepare a short methods/results section, finalize the required CV terms, and add the analysis code to the repository.
