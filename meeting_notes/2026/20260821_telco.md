## Mass Spectrometry Imaging

* Patrick has defined imaging metrics including total ion chromatogram, base peak fraction and reference mass-to-charge error.
* Matrix metrics are accompanied by matrix dimensions describing the spatial layout.
* Missing and zero values must remain distinct in matrix data. Regions that were not measured should be represented as `null`, since zero may itself be a meaningful measurement.
* The current mzQC implementation correctly writes and reads these missing values.
* Patrick has posted the proposed imaging metrics in a GitHub issue for review.
* The current figures still use placeholder CV accession numbers and will need to be regenerated after the terms are finalized.
* **Action – Patrick Boschmann:** Finalize the imaging CV terms and regenerate the figures with the final accession numbers.
