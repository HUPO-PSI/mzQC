## CV Term Categorization (Wout)

- Slides are on Slack. Motivation: the current single `is a` relation only gives the value format (single value, tuple, table, matrix), not the meaning.
- Proposal: a 2-3 level `is a` tree for semantic identity, with about 10 top-level families (e.g. separation performance, mass measurement performance, acquisition and sampling, data integrity).
- Plus typed relations: entity measured, property measured, input data required, statistical summary (optional), value structure (exactly one) and units.
- Example: XIC FWHM quantiles = separation peak characteristic, measures chromatographic peak FWHM, input is chromatographic feature data, summary is quantiles, value is a tuple in seconds.
- Enables queries such as "which metrics assess mass accuracy", "what can I compute without IDs", "which work for imaging".
- Also helps decide which metrics to compute at repository scale (PRIDE) so every aspect of an experiment is covered.
- David: many metrics fit several categories (e.g. TIC half-point in an isolation window is intensity, precursor and RT based). Wout: single parent is simpler but risks false negatives; multiple inheritance is allowed but risks over-annotation. No universal answer.
- Next step: test against existing metrics to see if single inheritance is limiting.
