## Mass Spectrometry Imaging

* Patrick Boschmann presented his work on quality control for mass spectrometry imaging. The group agreed that this is a valuable new mzQC use case, particularly for testing the currently underused matrix data type.
* Initial metrics will be identification-free and may include per-pixel total ion current, base-peak measures, spatial mass-error maps, acquired-pixel counts, and duplicate acquisitions.
* Null or `NaN` values must represent positions intentionally not acquired, while zero should indicate an expected measurement with no observed signal.
* **Action – Patrick Boschmann:** Create a prototype mzQC file with imaging matrix metrics, share examples on Slack, and open a GitHub issue for the required controlled vocabulary terms.
* Imaging may be added to the manuscript if a complete use case can be prepared within approximately one month.

## GC–MS Quality-Control Use Case

* Chris performed an analysis of Steffen Neumann's GC-MS data. The group supported adding the GC–MS use case to the main manuscript because it demonstrates mzQC applicability beyond LC–MS.
* The workflow detects nine reference compounds and summarizes retention-time deviation, signal-to-noise, peak width, variability, and missing compounds.
* Failed injections, degraded column performance, and reduced signal were clearly distinguishable.
* The unexpected loss of isovanillin requires interpretation from the Halle laboratory.
* **Action – Chris Bielow:** Correct the "IRQ" figure labels to "IQR," obtain laboratory metadata, complete the use-case text and figures, and submit approximately six new CV terms.
* Target completion date: approximately August 20.
